# Smart Crime Analytics System

A Python-based crime analytics and investigation management system developed using DBMS concepts.

## Features
- Complaint management
- Criminal search system
- Crime prediction
- Investigation tracking
- Crime map analysis
- Dashboard analytics
- Secure login system

## Technologies Used
- Python
- DBMS
- SQL

## Project Modules
- app.py → Main application
- analytics.py → Crime analytics
- complaint.py → Complaint handling
- crime_map.py → Crime mapping
- criminal_search.py → Criminal search module
- dashboard.py → Dashboard system
- db.py → Database connection
- investigation.py → Investigation management
- login.py → Authentication system
- prediction.py → Crime prediction module
